# Java Spring Boot Learning Project 

A full-stack web application developed as part of our 2nd-year Java module to learn and practice **Spring Boot** framework fundamentals.

## Project Overview

This project demonstrates the implementation of a complete web application using Spring Boot for the backend, connected to a frontend built with HTML, CSS, and JavaScript. The application utilizes cloud storage for managing media files.

## Technologies Used

### Backend
- **Java** - Core programming language
- **Spring Boot** - RESTful API development and backend framework
- **AWS S3** - Cloud storage for image management and retrieval

### Frontend
- **HTML** - Structure and markup
- **CSS** - Styling and layout
- **JavaScript** - Client-side interactivity

## Project Structure

```
├── backend/    # Spring Boot application
├── frontend/   # Web interface (HTML/CSS/JS)
└── .vscode/    # Editor configuration
```

## Learning Outcomes

Through this project, we gained hands-on experience with:
- Spring Boot application architecture
- RESTful API design and implementation
- Backend-frontend integration
- MVC (Model-View-Controller) pattern
- Dependency management with Spring Boot
- Cloud storage integration with AWS S3
